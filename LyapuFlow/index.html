The idea

Guide the flow. Preserve the prior.

LyapuFlow adds inference-time feedback to a pretrained flow model. It evaluates constraints on a predicted final sample, then chooses a minimum-norm correction using a Lyapunov decrease condition. A trust region limits the correction relative to the learned flow. No retraining is required.

01

Predict

Estimate the final sample from the current state and pretrained velocity.

02

Evaluate

Measure the predicted sample’s constraint violation.

03

Control

Apply bounded feedback only when the nominal dynamics need correction.
